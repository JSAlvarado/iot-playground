1. Watch the sensors

Gauges show what each sensor measures right now, with the healthy range in green. Tap one to learn what it means.

2. Write rule cards

"IF oxygen is below 4 THEN aerator ON." Simple rules like these are how real controllers decide what to do.

3. See the real code

Every game turns your rules into Arduino code, so you can see how they would run on a real microcontroller.

Made by Johnstheward S. Alvarado. The simulations are simplified to run in a browser, but their healthy ranges follow published sources, listed in each game's Learn tab. Your stars are saved only on this device. Sound starts when you first tap a game, including rain, wind and birds that follow the weather; the speaker button turns effects and music on or off.
